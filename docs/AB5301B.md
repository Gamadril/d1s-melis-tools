# MCU update extraction with `mcu_tool`

`mcu_tool` decodes and extracts `LTTMcu.bin` updates for the Bluetrum AB5301B companion MCU in F133-based devices.
It reads an update file and writes its contents to a new directory.
It does not flash devices or repack updates.

## Get the binary

Release bundles include `bin/mcu_tool` (`mcu_tool.exe` on Windows).
Run the examples below from that `bin/` directory.

## Extract an update

```bash
./mcu_tool extract path/to/LTTMcu.bin lttmcu-extracted
```

The output directory must not already exist, and its parent directory must exist.
The tool refuses existing files, directories and symlinks at the output path.
Decoding and integrity checks finish before output files are created.

On Windows, use `.\mcu_tool.exe` in place of `./mcu_tool`.

## Options

```bash
# Validate and print the manifest without writing files
./mcu_tool extract LTTMcu.bin lttmcu-check --dry-run

# Extract only the outer package, without decoding its contents
./mcu_tool extract LTTMcu.bin lttmcu-package --outer-only

# Show all extract options
./mcu_tool extract --help
```

`--dry-run` still requires an output argument, and that path must not already exist.
It prints the file information and validation results to the terminal.

`--outer-only` can extract the package from updates whose inner format or boot loader is unsupported.
It checks only the outer wrapper; it does not validate or decode the contents of `package.bin`.
It can be combined with `--dry-run`.

## Output files

| File | Contents |
| --- | --- |
| `original.bin` | Copy of the input update |
| `package.bin` | Update package with the outer wrapper removed and decoded |
| `xcod.bin` | Decoded main executable |
| `xres.bin` | Resource/audio data, when present |
| `boot.bin` | Decoded boot loader |
| `updater.bin`, `ram.bin`, `helper.bin` | Decoded update and startup components |
| `wrapper-header.bin`, `flash-header.bin`, `flash-directory.bin` | Update headers and directory |
| `raw/` | Additional package sections and metadata |
| `manifest.txt` | File information, validation results, hashes and source offsets |

With `--outer-only`, the output contains only `original.bin`, `wrapper-header.bin`, `package.bin` and `manifest.txt`.

## Supported files and errors

Extraction has been verified with several update samples from other systems since I cannot find any update files for HZ-B500.
These use the same command without additional decoding parameters.
Other Bluetrum updates may use unsupported formats or bootloaders.

A write error can leave a partial output directory.
`manifest.txt` is written last, after the other output files have been written.

Successful extraction does not confirm that an update is compatible with your device.
Extracted files are for inspection; the tool does not produce a flashable replacement update.
